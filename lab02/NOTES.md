1. рабочая папка - это директория, в которой я запускаю команды git и редактирую файлы
2. git - это программа отслеживающая контроль версий, а GitHub - это сайт похожий на облако с информацией где можно хранить удаленные копии репозиториев, также делиться им с другими. git diff показывает изменения в рабочей папке\*\*,\*\* которые еще не добавлены в индекс, а команда git diff --staged показывает уже добавленные изменения



3\. использованные команды. git status - показывают состояние рабочей папки и индекса в данный момент. git diff  показывает что изменили, но пока не добавили. git diff --staged показывает, что попадает в следующий коммит



4\. ветка (branch) - отдельная линия разработки, позволяющая вносить изменения не затрагивая освновную ветку main. слияние (merge) это процесс объединения изменений из одной ветки в другую
